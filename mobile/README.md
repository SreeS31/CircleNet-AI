# CircleNet-AI Mobile Modules

This directory contains the mobile applications for CircleNet-AI.

## Current module

- `flutter-app`: Android, iOS, and web-preview Flutter application delivered by Milestone 6.

## Scope

The mobile layer currently provides:

- Authentication and secure session flows
- Adaptive phone and tablet navigation
- Circle and relationship interactions
- Private and group message viewing and posting
- Authenticated attachment viewing
- Profile management
- Shared API contracts with platform services

Native file selection/upload, full WebRTC calling, offline synchronization, push notifications, and store release automation are tracked in the pending roadmap milestones.
